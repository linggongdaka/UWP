# 数据集卡片

## 目标

WorkforceOps Benchmark 120 用于评估 Agent 能否在灵活用工业务中完成一次受约束的业务闭环：识别范围、调用业务能力、引用证据、遵守权限、保护敏感信息、等待人工确认或升级，并输出可复核结果。

## 不测什么

它不以语言风格或回答篇幅为主要目标，也不证明模型可以独立作出候选人入场、收入调整、赔付、责任认定等高风险决定。

## 数据构成

- 120道业务题。
- 30组模拟门店授权范围。
- 90道门店月度汇总题，30道灵工伙伴明细题。
- 智能面试场景包含8名合成候选人。
- 9类业务场景、5类权限处置、24项业务能力。

## 数据来源与隐私

题目由真实业务结构和经脱敏、聚合后的指标构建；灵工伙伴明细使用确定性模拟指标。公开包仅保留评测所需的模拟标识、业务上下文、聚合或安全明细指标及评分要求。内部来源表、SQL、路径、客户标识和个人敏感信息均已移除。

## 已知限制

- 难度标签受本轮四模型表现影响，后续模型可能改变题目的相对难度。
- 题包聚焦服务业灵活用工流程，不能外推到所有行业。
- 模型成绩会受模型版本、提示词、工具实现、并发与运行环境影响。
- 数据集公开后存在训练污染风险，后续版本需要保留未公开题或滚动补题。
