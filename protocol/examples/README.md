# UGP Examples

This directory contains machine-readable examples for the Universal Gig Protocol.

| File | Purpose |
|---|---|
| [well-known-ugp.json](./well-known-ugp.json) | Example `/.well-known/ugp` profile document. |
| [capability-response.json](./capability-response.json) | Example response that declares active capabilities, policy decision, mandate request, and audit reference. |
| [enterprise-operations-flow.json](./enterprise-operations-flow.json) | Example enterprise-side workforce management flow built on `org.ugp.enterprise_operations`. |
| [policy-decision-mandate-required.json](./policy-decision-mandate-required.json) | Example policy response for a high-risk settlement action. |

All examples use synthetic aliases and do not contain real worker identity data.
